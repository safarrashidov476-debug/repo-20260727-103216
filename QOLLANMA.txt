A) FAYL YUKLASH FOIZINI E'LON QILISH

Fayl: TMessagesProj/src/main/java/org/telegram/ui/Cells/ChatMessageCell.java

"onProgressDownload" va "onProgressUpload" metodlarini toping.
Har birining ichiga, boshida shuni qo'shing:

    private int lastAnnouncedProgressPercent = -1;
    // (bu qatorni klass ichiga, metoddan tashqariga qo'shing - bir marta)

Va har bir metod ichida (progress % hisoblangandan keyin):

    int percent = (int) (progress * 100);
    if (percent - lastAnnouncedProgressPercent >= 10 || percent == 100) {
        lastAnnouncedProgressPercent = percent;
        sendAccessibilityEventForVirtualView(
            MessageAccessibilityNodeProvider.HOST_VIEW_ID,
            AccessibilityEvent.TYPE_ANNOUNCEMENT,
            percent + " foiz"
        );
    }

B) "MUHOKAMANI KO'RISH" MENYU BANDINI KANAL POSTLARIGA QO'SHISH

Fayl: TMessagesProj/src/main/java/org/telegram/ui/ChatActivity.java

Shu qatorni qidiring (2 marta uchraydi, ikkalasiga ham qo'shing):

    options.add(OPTION_VIEW_REPLIES_OR_THREAD);

Shu qatordan keyin, yopilish qavsidan ({}) so'ng, shuni qo'shing:

    if (!isThreadChat() && chatMode != MODE_SCHEDULED && currentChat != null
        && ChatObject.isChannel(currentChat) && !currentChat.megagroup
        && currentChat.has_link && primaryMessage != null) {
        items.add(LocaleController.getString(R.string.ViewDiscussion));
        options.add(OPTION_VIEW_REPLIES_OR_THREAD);
        icons.add(R.drawable.msg_viewreplies);
    }
